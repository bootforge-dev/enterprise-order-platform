# Enterprise Order & Fulfillment Platform

Production-style event-driven microservices application built using Java and Spring Boot.

## Architecture

The platform consists of multiple independently deployable microservices.

## Technologies

- Java
- Spring Boot
- Spring Cloud
- Spring Kafka
- MySQL
- Redis
- Docker
- Kubernetes
- AWS
- Terraform
- Prometheus
- Grafana

## Services

- API Gateway
- Auth Service
- Customer Service
- Product Service
- Inventory Service
- Order Service
- Payment Service
- Fulfillment Service
- Shipping Service
- Notification Service
- Audit Service
